# Módulos o épicas a desarrollar.
# Roadmap de Desarrollo — Frontend Público

## Fase 1: Identidad Institucional y Estructura Base
- [ ] Configuración del entorno con Vite + React + TypeScript + Tailwind CSS.
- [ ] Implementación de Layout institucional (Header SDS, Footer con datos de contacto, enlaces de accesibilidad).
- [ ] Landing Page informativa (Sección "¿Qué es Renacimiento Verde?", objetivos y beneficios de especies nativas).

## Fase 2: Impacto Visual y Métricas
- [ ] Dashboard de métricas globales:
  - Contador animado y barra de porcentaje de árboles sembrados respecto a la meta estatal.
  - Indicadores de municipios beneficiados y lugares de entrega activos.

## Fase 3: Mapa Interactivo de Reforestación (GIS Light)
- [ ] Integración de mapa interactivo con Leaflet / MapLibre.
- [ ] Marcadores interactivos personalizados por tipo de árbol o zona.
- [ ] Modal / Popover descriptivo al hacer clic en un marcador (Foto/ícono, cantidad, fecha de siembra, especie nativa y municipio).
- [ ] Filtros básicos en el mapa (por municipio o tipo de especie).

## Fase 4: Portal de Entregas y Solicitudes
- [ ] Sección "Puntos de Entrega y Viveros SDS" (Horarios, mapa/ubicación, disponibilidad de stock según época de lluvias).
- [ ] Requisitos e información para solicitud de árboles (Escuelas, Ayuntamientos, Sociedad Civil).
- [ ] Formulario dinámico de solicitud pública con validaciones de formulario.

## Fase 5: Arnés de Calidad, SEO y Optimización
- [ ] Optimización de imágenes y carga diferida (Lazy loading de mapa y fotografías).
- [ ] Auditoría de Accesibilidad (Lighthouse score > 90, WCAG 2.1 AA).
- [ ] Cobertura de pruebas unitarias para componentes críticos.
